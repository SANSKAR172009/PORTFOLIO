Active Project

NEBULA — Groq AI Playground

An AI playground for exploring model responses, prompt analysis, and streaming inference through Groq. The interface exposes model controls and response telemetry so a user can inspect a request as it runs.

ProblemModel experimentation is difficult to compare when prompt controls and request feedback are scattered across tools.

ArchitectureA JavaScript browser interface connects to a Groq API client for model requests and streamed responses; an optional Vercel Edge API route is documented for proxy deployment.

Individual projectI built the playground interface, model and prompt controls, streaming display, and inference telemetry.

MiniGit — Python Version-Control CLI

A Python implementation that makes Git’s object model and repository operations inspectable. The portfolio’s terminal is a browser-side demonstration of selected commands; it does not execute the Python CLI.

ProblemGit’s object model is hidden behind familiar commands, making it hard to see how files become stored snapshots.

ArchitecturePython command modules work with repository objects, the staging index, references, and the working tree. Architecture notes and source modules are linked below.

Individual projectI built the Python implementation and this portfolio’s interactive command walkthrough to explain object hashing, staging, commits, and status.
