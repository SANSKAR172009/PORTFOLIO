MiniGit — Python Version-Control CLI

Git Internals & SHA-1 Store

A Python implementation making Git’s object model and repository operations inspectable. The sandbox here simulates selected commands in-browser.

ProblemGit’s object model is hidden behind familiar commands, making it hard to see how files become stored snapshots.
ArchitecturePython command modules work with repository objects, the staging index, references, and the working tree.
Individual ProjectBuilt the Python implementation and interactive command walkthrough for hashing, staging, commits, and status.
Python SHA-1 Objects Trees & Commits CLI

Self-Attention Explorer

Illustrative Token Weights

Browser visualization letting visitors select a word and inspect its illustrative relationships to other words in a sample sentence.

ProblemSelf-attention is easier to discuss when a learner can see how changing the selected token changes displayed relationships.
